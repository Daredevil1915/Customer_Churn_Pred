# 📉 Customer Churn Prediction App

A machine learning web application built using **Streamlit** and **Artificial Neural Networks** to predict whether a bank customer is likely to churn.

## 🚀 Features
- Interactive UI with modern design
- Real-time churn probability prediction
- ANN model trained on customer data
- Proper preprocessing (Encoding + Scaling)

## 🛠 Tech Stack
- Python
- Streamlit
- TensorFlow / Keras
- Scikit-learn
- Pandas & NumPy

## ▶️ How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
